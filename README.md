# Подсистема «Отпуска» отдела кадров

Веб-ассистент на Next.js + TypeScript + собственный MCP-сервер на Python.

## Предметная область

Подача заявления на отпуск, согласование с учётом правил очередности
и категорий сотрудников, отметка ухода/выхода, график отпусков,
расчёт остатка дней и пересечений в отделе.

## Структура

- `mcp-server/` — MCP-сервер на Python (инструменты, ресурсы, промпты, SQLite)
- `web/` — Next.js-приложение (панель + чат)
- `docs/` — проектирование и схема БД

## Статус

В разработке. Этап 1 (проектирование) — готов.
