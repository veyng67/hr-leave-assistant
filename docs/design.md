# Проектирование подсистемы «Отпуска»

## 1.1. Предметная область

Подсистема отдела кадров «Отпуска». Позволяет:
- сотруднику — подать заявление на отпуск;
- руководителю/кадровику — согласовать заявку с учётом правил очередности и категорий;
- кадровику — отметить фактический уход/выход;
- вести годовой график отпусков;
- автоматически считать остаток дней и проверять пересечения в отделе.

Ключевая особенность: при согласовании проверяются два бизнес-правила:
1. Правило очередности — сотрудники с более высокой категорией (льготники, ветераны, многодетные) имеют приоритет при пересечении дат.
2. Правило пересечений — в отделе не может одновременно отсутствовать больше N% сотрудников.

## 1.6. Валидация и ToolError

- Формат даты YYYY-MM-DD
- date_end >= date_start
- Дни <= остатка
- Пересечение в отделе <= max_concurrent_absent
- Заявка существует
- Статус подходит
- Отказ внешнего сервиса
